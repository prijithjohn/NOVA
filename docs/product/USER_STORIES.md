# NOVA User Stories

These stories define the intended product behavior. They are not an implementation commitment for Phase 0.

## Assistant

- As a user, I want to ask questions about my NOVA context so that I can make decisions with less searching.
- As a user, I want the Assistant to distinguish known information from suggestions and uncertainty so that I can judge its response.
- As a user, I want to review and confirm consequential changes so that assistance does not silently alter my records or commitments.

## Memory

- As a user, I want to save useful personal context so that I do not have to reconstruct it later.
- As a user, I want to find, correct, and delete stored memories so that my personal context remains accurate and under my control.

## Goals and Tasks

- As a user, I want to define a goal with an outcome and time horizon so that my intent is concrete.
- As a user, I want to break a goal into tasks and track their status so that progress is visible.
- As a user, I want to see which tasks support a goal so that I can choose meaningful next actions.

## Calendar

- As a user, I want to represent commitments and planned work in time so that my plans fit my available capacity.
- As a user, I want to relate planned work to tasks and goals so that my calendar reflects priorities.

## Finance

- As a user, I want to record and review financial information I choose to provide so that I can understand my situation.
- As a user, I want financial summaries to be traceable to their source records so that I can verify them.

## Documents

- As a user, I want to organize documents and connect them to relevant context so that important information is easier to use.
- As a user, I want extracted or summarized document context to remain distinguishable from the original document so that I can verify it.

## Analytics

- As a user, I want to see progress, workload, time, and financial summaries derived from my records so that I can spot patterns.
- As a user, I want analytics to explain their inputs and limits so that I do not mistake incomplete data for certainty.

## Cross-Domain

- As a user, I want one Assistant to work across my approved domains so that I can move from understanding to action without duplicating context.
- As a user, I want my data isolated from other users so that my personal operating picture remains private.
